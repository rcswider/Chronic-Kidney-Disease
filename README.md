# Chronic Kidney Disease Data Analysis

## Project Overview

This project analyzes a dataset containing clinical and laboratory data to identify indicators and potential predictors of Chronic Kidney Disease (CKD). The analysis uses Python for data exploration, data cleaning, statistical analysis, visualization, and machine learning model development.

## Objectives

- Explore and assess the dataset
- Identify and address missing data
- Clean and wrangle the data
- Calculate and interpret descriptive statistics
- Identify and visualize important relationships among variables
- Analyze potential predictors of Chronic Kidney Disease
- Develop and evaluate machine learning models for CKD prediction

## Tools

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Repository Structure

- `data/` — Dataset files
- `notebooks/` — Jupyter notebooks
- `reports/` — Project reports
- `presentations/` — Presentation materials
- `images/` — Visualizations and figures

## Data Source

The original Chronic Kidney Disease dataset is available through the UCI Machine Learning Repository. The dataset contains clinical and laboratory observations collected over approximately a two-month period.
